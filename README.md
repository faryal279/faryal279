### 🔥 Featured Projects

#### 🌊 [AquaVision AI — Water Quality Intelligence System](https://huggingface.co/spaces/faryal-idrees/AquaVision-AI-Intelligence)
Multi-agent water quality analysis platform powered by Groq-hosted LLMs (Llama 3.3 70B & 3.1 8B). Features 5 specialized AI agents, document-grounded Q&A, and interactive Plotly dashboards. **Selected & showcased at HEC National Hackathon 2025.**

#### 📝 Web-Based AI Question Generator
Full-stack web app that generates academic questions from input text using LLM APIs. Built and evaluated for real-world educational deployment.

BERT-based language model project for next-word prediction and grammar error detection/correction, using tokenization and masked language modeling for fine-tuning.
